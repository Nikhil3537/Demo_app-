# Demo Task App

A simple Ruby on Rails web application for creating, managing, and tracking tasks.

## Features

- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Task status management
- CRUD operations
- Rails MVC architecture
- ActiveRecord database integration

## Technologies Used

- Ruby
- Ruby on Rails
- SQLite3
- HTML
- CSS
- JavaScript
- ERB
- ActiveRecord
- Git
- GitHub
